Guitar to Piano

24 Mar 2024
Code Music

Google sheets app prototype: Guitar to Piano.

Development

Problem:
knowing musical notes and chords on guitar, but not on piano
Solution:
interactive note finder map from guitar to piano
Implementation:
proof-of-concept prototype in google sheets, with
links to reverse chord finder, to
create chord libary.
considered note shifting to expand chord colours
Limitations:
only considers 2.5 octaves
Further development ideas:
name the notes in tab
name the notes on fretboard
show the notes on a stave
extend the range of notes
add macro button to add more chord mapping entry modules
expand note shift capabilities
calculate the name of the chords
links to reverse chord finder
